行迹 v6 · GitHub Pages 上传包

使用方法：
1. 把本文件夹内的所有文件上传到 Cloezhou/c-loe 仓库根目录。
2. 必须同时上传 day-map.png、night-map.png、style.css、app.js、index.html 和 .nojekyll。
3. 覆盖旧版同名文件；旧 assets 文件夹可以删除。
4. GitHub Pages 选择 main 分支和 /(root)。

功能：
- 暖色水墨白天地图
- 深蓝发光夜间地图
- 咖啡店、景点、书店、餐厅甜品、展览场馆、公园、夜间去处筛选
- 距离和点亮状态筛选
- 附近地点列表与详情
- 到店打卡点亮专属徽章
- 徽章收藏与我的行迹
- 打卡和主题状态保存在当前设备
