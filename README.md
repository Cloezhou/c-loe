# 行迹 · 长沙城市打卡地图 v4

这是可直接发布到 GitHub Pages 的静态网页版。

## 上传方法

将本文件夹中的 `index.html`、`.nojekyll` 和 `assets` 文件夹全部上传到仓库根目录，覆盖旧版文件。

GitHub 仓库中如果仍有旧的 `app.js`、`style.css` 或 `styles.css`，可以删除，避免以后混淆。

## 新版功能

- 咖啡店、风景名胜、书店、餐厅甜品、展览场馆、公园、夜间去处
- 1、3、5、10 公里距离筛选
- 未点亮、已点亮状态筛选
- 地图地点与下方列表联动
- 每个地点均可打卡并点亮专属徽章
- 统一使用“打卡 / 点亮徽章”，不使用“盖章 / 集章”
